## How to Use the Catalog Page

- Start with the master catalog if you are still choosing the right product family.
- Use the focused brochure files once you already know the product direction.
- Send the file name or page link together with your inquiry so we can respond more accurately.

## What to Send with Your Inquiry

- destination country and nearest port
- product family or file you are referring to
- quantity
- use case
- expected timeline
- any drawings, layout ideas, or reference photos
